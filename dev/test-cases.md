# Xray Test Cases

Run these as smoke tests before publish or install changes.

## 1. Fake/demo target

Goal:

- confirm Xray can lead with the strongest contradiction
- confirm it uses a blunt negative frame when warranted
- confirm source lines stay literal and non-blank

## 2. Positive-but-careful target

Goal:

- confirm Xray can use `LIVE PLUMBING`
- confirm it credits real product/router/contract plumbing
- confirm it states when final execution/settlement was not personally verified

## 3. Product-real, token-unclear target

Goal:

- confirm Xray separates product legitimacy from token legitimacy
- confirm strong product proof does not automatically imply official token endorsement

## 4. Token-first edge case

Goal:

- confirm Xray stays concise and does not try to replace Scoutr
- confirm token/launch detail is only included when it materially changes the verdict
